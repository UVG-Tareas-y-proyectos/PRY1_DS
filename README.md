# Proyecto 1 - Obtención y limpieza de datos

Equipo: Ihan Marroquin (23108), Diego Patzan (23525) y Milton Polanco.

El proyecto contiene adquisición, consolidación, diagnóstico, plan de limpieza y documentación de variables.

Para ejecutar la consolidación y el diagnóstico:

    python -m pip install -r requirements.txt
    python -m src.consolidar

Documentación: docs/METODOLOGIA.md, docs/PLAN_LIMPIEZA.md, docs/LIBRO_PRELIMINAR.md, docs/REPRODUCIR_AVANCE.md y los dos PDF originales en docs/referencias.

Los CSV crudos y el catálogo territorial se verifican mediante sumas SHA-256. El comando de diagnóstico no modifica los datos crudos.
